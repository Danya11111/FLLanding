# FLLanding

Премиальный лендинг IT-фрилансера Архипова Даниила.  
Стек: React 19 + Vite, Framer Motion, @react-three/fiber/@drei для 3D-сцены, кастомный CSS.

## Скрипты

```bash
npm install        # установка зависимостей
npm run dev        # локальная разработка с HMR
npm run build      # сборка production-версии (dist/)
npm run preview    # предпросмотр собранной версии
npm run lint       # проверка ESLint
```

## Быстрый запуск через Docker

### Автоматический запуск (рекомендуется)

Используйте PowerShell скрипт `start.ps1` для управления контейнером:

```powershell
# Запустить сайт (автоматически соберёт образ, если нужно)
.\start.ps1 start

# Остановить сайт
.\start.ps1 stop

# Перезапустить
.\start.ps1 restart

# Показать статус
.\start.ps1 status

# Показать логи в реальном времени
.\start.ps1 logs

# Только собрать образ без запуска
.\start.ps1 build
```

Скрипт автоматически:
- Проверяет наличие Docker
- Собирает образ, если он отсутствует
- Проверяет занятость порта (по умолчанию 8080)
- Запускает контейнер в фоновом режиме
- Предоставляет удобные команды управления

### Ручной запуск

1. Убедитесь, что установлен Docker Desktop (Windows/macOS) или docker engine (Linux) и демон запущен.
2. В корне проекта соберите production-образ:

   ```bash
   docker build -t fllanding:latest .
   ```

   Многоэтапный Dockerfile сначала собирает Vite-проект, затем упаковывает статику в nginx.
3. Поднимите контейнер и пробросьте порт 80 на localhost (можно выбрать любой порт хоста, например 8080):

   ```bash
   docker run --rm -p 8080:80 fllanding:latest
   ```

4. Перейдите в браузере на `http://localhost:8080` — сайт обслуживается nginx внутри контейнера. Остановить можно `Ctrl+C` (контейнер удалится из-за флага `--rm`).

## Структура

- `src/App.jsx` — основная страница со всеми секциями.
- `src/App.css`, `src/index.css` — глобальные стили и шрифты.
- `Dockerfile` — многоэтапная сборка (Node builder + nginx runtime).
- `.dockerignore` — исключения для более быстрой docker-сборки.
